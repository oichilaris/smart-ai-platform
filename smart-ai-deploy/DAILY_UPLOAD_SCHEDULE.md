### 📊 KONTEN PER KATEGORI

#### 1. IMPAC.art — Jasa Web Development
**Frekuensi: 2x/hari (Senin, Rabu, Jumat)**
- **Konten:** Portfolio showcase, before/after, case study, tutorial snippet
- **Platform:** Instagram (visual), LinkedIn (B2B), Twitter (tech)
- **CTA:** "DM untuk konsultasi gratis" → notifikasi ke user
- **Harga:** Rp 250.000+ (sesuai kompleksitas)
- **Jika ada request jasa:** Kirim detail + harga ke user via Telegram

#### 2. AB Nutrisi — Produk Fisik
**Frekuensi: 2x/hari (Selasa, Kamis, Sabtu)**
- **Konten:** Before/after tanaman, testimoni petani, tips pertanian, promo
- **Platform:** Facebook (target petani), Instagram (visual), TikTok (video)
- **CTA:** "Order via WhatsApp/Marketplace"
- **Harga:** 1L Rp 50.000 (hemat 23.000), 5L Rp 175.000
- **Target:** 50 orders/bulan

#### 3. Affiliate Marketing
**Frekuensi: 1x/hari (Setiap hari)**
- **Konten:** Review produk, comparison, tutorial, "best of" lists
- **Platform:** Blog (Vercel), YouTube (long-form), Twitter (thread)
- **CTA:** Link affiliate di bio/deskripsi
- **Program:** Amazon Associates, SaaS (Canva, Shopify, software AI)
- **Target:** $20-100/bulan passive

#### 4. Micro-SaaS / Digital Tools
**Frekuensi: 1x/hari (Senin-Jumat)**
- **Konten:** Product demo, feature highlight, user testimonial, tutorial
- **Platform:** Twitter (tech), LinkedIn (B2B), Product Hunt
- **CTA:** "Try free" → subscription $5-20/bulan
- **Tools:** Document generator, SEO scanner, data processor

#### 5. Digital Products (Gumroad)
**Frekuensi: 1x/hari (Setiap hari)**
- **Konten:** Product showcase, testimonial, use case, promo
- **Platform:** Twitter, Instagram, Pinterest, Reddit
- **CTA:** "Get it now" → Gumroad link
- **Produk:** 10 produk live, harga $5-18

### 🔔 PROTOKOL REQUEST JASA
Jika ada yang meminta jasa (web dev, desain, CV/PT):
1. **Catat detail request** (nama, kontak, kebutuhan, budget)
2. **Kirim ke user via Telegram** dengan format:
   ```
   📋 REQUEST JASA BARU
   Nama: [nama]
   Kontak: [kontak]
   Kebutuhan: [detail]
   Budget: [budget]
   Estimasi Harga: [harga kami]
   Rekomendasi: [terima/tolak/negosiasi]
   ```
3. **Tunggu konfirmasi user** sebelum eksekusi
4. **Jangan kirim detail ke Discord** (sesuai permintaan)
